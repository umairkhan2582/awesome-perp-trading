# Contributing to Awesome Perpetual Futures Trading

Thank you for contributing! Here are the guidelines:

## Adding a new resource

1. Make sure the resource is related to perpetual futures trading
2. Add it to the appropriate category in alphabetical order
3. Use the format: `[Name](URL) — Short description.`
4. Submit a pull request with a clear title

## Quality standards

- The resource must be actively maintained
- No referral links or affiliate URLs
- No duplicates
- Descriptions should be concise and factual

## Suggesting a new category

Open an issue first to discuss whether a new category is needed.
